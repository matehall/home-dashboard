Prior investigations, decisions, incidents and lessons for this project are kept in the AgentOps hub, not in this repository.

Before starting work, read the hub's `AGENTS.md` and the project's `agentops/index.md`. Record new findings in the hub, not here. If the hub is not on this machine, ask the user before continuing.
